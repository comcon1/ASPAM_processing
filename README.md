# ASPAM processing

Processing scripts of animal spontaneous physical activity data generated by ASPAM (https://github.com/comcon1/ASPAM) or related applications. Analysis includes isolation of local run in 5-second intervals, making histograms of running activity in the day-time and in the night-time, calculating statistics of cumulative run and average speed between day periods and animal groups, etc.
